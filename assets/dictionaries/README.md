# Dictionary assets

## Source location

The untouched upstream ECDICT checkout lives outside the web project at
`../third-party/ECDICT-master/` relative to the `langLSRW` repository. Keeping
it outside this directory prevents source datasets and maintenance tools from
entering website deployments.

The initial dictionary build uses only `ecdict.csv`. The larger `stardict.7z`
dataset remains untouched but is not used by the runtime build. Set the
`ECDICT_SOURCE_DIR` environment variable to override the default source path.

## `runtime/ecdict/`

Browser-ready, versioned output generated by `tools/build-ecdict.py`:

- `ecdict.sqlite.gz`: complete basic ECDICT SQLite package loaded into browser OPFS.
- `manifest.json`: version, entry count, byte sizes, hashes, and source provenance.
- `LICENSE`: ECDICT license distributed with the runtime data.

The uncompressed `ecdict.sqlite` file is a temporary build artifact and is not
kept after a successful build.

## Spanish source candidates

The owner-provided Spanish Wiktionary source is kept outside the deployed web
project at `../third-party/Spanish/kaikki.org-dictionary-Spanish.jsonl`.
Generate the browser package with:

```text
npm run build:dictionary:es
```

The generated `runtime/spanish-wiktionary/` package uses the same SQLite table
shape as ECDICT so the dictionary Worker can eventually load it through the
same storage and lookup contract. The first build stores Kaikki/Wiktionary
English glosses as the meaning text; cached Chinese learning explanations are a
future layer, not part of the raw dictionary import.

The first complete build from the 2026-09-27 owner-provided source produced:

- 770,716 merged dictionary entries.
- 436,391,936 bytes uncompressed SQLite.
- 70,042,471 bytes compressed `spanish-wiktionary.sqlite.gz`.
- SQLite SHA-256:
  `28ba43f0ec67507af72f866c24be8aa73e1b00abfdd4e27da9287b1176e6f613`.
- Package SHA-256:
  `2a5f13af97f31a3b68e9c579b0ab5954446388f293e2e75d8c9e3645ee082bc6`.

`../third-party/Spanish/spa-eng/spa.txt` is not a dictionary source. It is a
Spanish-English sentence library candidate from Tatoeba / manythings.org and
should be handled by sentence-library tooling instead of dictionary tooling.
