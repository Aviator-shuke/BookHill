# langLSRW 项目状态

最后更新：2026-09-30

详细行为、存储、同步和构建规则维护在 [`MECHANISMS.md`](MECHANISMS.md)。已接受的多语言适配器方向，包括未来的德语和法语包，记录在 [`MULTILINGUAL_ARCHITECTURE.md`](MULTILINGUAL_ARCHITECTURE.md)。西班牙语是第一个新增语言，目前处于早期实现阶段；它的已实现范围、剩余发布步骤和语言学风险记录在 [`SPANISH.md`](SPANISH.md)。通用适配器架构只完成了部分抽取，德语和法语包尚未实现。

## 当前阶段

langLSRW 目前是一个本地优先开发阶段的个人语言学习原型。听力和口语流程已经可用于日常本地测试。阅读、写作、更广的复习池和文章生成仍是后续工作。生产部署已连接 Supabase，并且已在部署站点验证 Google 登录。正式发布方向是登录账号云端优先：云端作为跨设备存储的权威来源，浏览器数据作为离线缓存；显式的本机用户模式将继续保持纯本地。

本地测试仍是默认开发流程。运行 `tools/start-langlsrw-server.bat`，然后打开 `http://localhost:8848/`。源码仓库已连接 Vercel，第一次生产部署已于 2026-09-24 成功完成。Vercel 托管前端，Supabase 现在提供 Google 身份认证和已有的初始同步后端。跨设备同步仍需要明确的端到端验证。未来部署和外部服务变更仍需要所有者明确请求。

## 已实现

### 共享应用

- 四段导航：`听说 -> 读 -> 写`；阅读和写作目前仍是占位。
- 紧凑的 `英 / 西` 学习语言控件位于 `听说读写` 导航左侧，选中的学习语言保存在本地。英语仍是完整的运行时语言。西班牙语现在已有自己的内置材料、词典、文本规则、地区语音设置、收藏、单词复习记录、频率分类和上次位置；语法分析、翻译缓存身份、备份和云同步尚未按语言为西班牙语划分作用域。
- 选择 `西` 会把练习切换到内置 `常用西语句库`（`assets/libraries/common-spanish-134910/`，134,910 个 Tatoeba 句子，经 manythings.org `spa-eng`，西班牙语 + 英语翻译，CC BY 2.0 FR），并恢复独立的西班牙语上次位置。TTS 和语音识别跟随口音选择器中选择的西班牙语口音地区（默认 `西班牙` es-ES，另有 `墨西哥`、`美国`、`阿根廷`、`哥伦比亚`、`智利`，以及音频材料用的 `原声`；材料和记录目前不按地区区分），西班牙语的口音/声音选择与英语分开保存。单词收藏、句子收藏、`收藏` 对话框和 `用户收藏` 句库选项在西班牙语中可用，数据与英语分开存储（英语保留原始键；西班牙语使用 `...:es` 键）；`收藏` 对话框隐藏仅英语可用的分类和 BNC/当代语料/柯林斯排序，收藏里的 背单词（预习 / 复习 / 测验、状态图标、手动掌握、掌握卡片）在西班牙语中按英语同样方式工作，但使用西班牙语作用域记录、在字母槽中隐藏重音字母、使用英语释义，并使用 常用 3000 干扰项；西班牙语 词库 有字幕频率分类（常用 500 / 1000 / 2000 / 3000 / 5000 / 10000 / 全部）、频率排序和分类卡组，来自 `frequency.tsv`（17,458 个词元），由词典 Worker 导入已安装数据库，无需重建包；AI 语法分析在西班牙语中保持关闭。西班牙语模式下，在单词条目的英语含义/定义中或练习区英语翻译中右键点击英语单词，会在上层打开英语词典（ECDICT）弹窗，带英语发音，并把五星收藏保存到英语收藏。英语翻译旁的 `中译` 按钮会把当前句子的翻译替换为浏览器翻译的中文（`英译` 切回；每句一次性使用，不缓存）。分词和听写评分使用独立的按语言规则（`src/languages/en/text.js`、`src/languages/es/text.js`）：西班牙语保持重音词完整，并严格评分重音（所有者 2026-09-28 决定：缺少或错误重音就是错误，`ñ` 永远不是 `n`），英语保留自己的 ASCII 规则。
- 西班牙语默认区域是西班牙西语 `es-ES`。根据所有者 2026-09-28 的决定，口音选择器也提供 `es-MX`、`es-US`、`es-AR`、`es-CO` 和 `es-CL`（Edge 在线自然声音）；这些地区目前只影响 TTS 声音和语音识别，不影响材料、记录或缓存。
- 浏览器相关的西班牙语能力已明确限定作用域。所有者端 Edge 已验证 `speechSynthesis` 西班牙语声音，包括 `es-ES`。西班牙语句库中文翻译是浏览器 `Translator API` 从人工英语列机器翻译而来（`en -> zh`；所有者 2026-09-28 决定，因为浏览器机器翻译以英语为中转）；只有没有准确英语的行才使用 `es -> zh`，如果 `en -> zh` 不可用，工具会报错。
- 本机用户、IndexedDB 中按身份划分的个人数据（`src/user-data.js`，见 `USER_DATA.md`）、用户切换、当前身份记录的 JSON 导入/导出，以及设置重置。
- 四个主题，按此顺序循环：护眼（默认）、浅色、灰色、黑色。
- 英语内容字体和中文 UI/翻译字体分别设置。
- 所有语法角色的颜色可配置，包含取色器、可编辑 HEX 值、常用色板、本地持久化和重置默认值。
- 听力工具栏把朗读操作保留在口音选择器旁，并提供紧凑的 `0.5x-2.0x` 语速步进器，以 `0.1x` 递增，句子播放、自动播放和单词播放共用。
- 可安装的本地 ECDICT 基础，使用专用 Worker 中的 SQLite WASM 和浏览器 OPFS 持久化。页面通过与存储无关的词典服务访问它，而不是从 UI 代码直接发 SQL。
- 已为所有者提供的 Kaikki Spanish Wiktionary JSONL 源 `../third-party/Spanish/kaikki.org-dictionary-Spanish.jsonl` 添加西班牙语词典构建路径。它会在 `assets/dictionaries/runtime/spanish-wiktionary/` 下生成 ECDICT 兼容的 SQLite gzip 包，当前含义层使用 Kaikki/Wiktionary 英语释义。第一次完整构建包含 770,716 个条目；SQLite 数据库为 436,391,936 字节，gzip 包为 70,042,471 字节。之后已经加入收藏隔离、西班牙语单词学习和西班牙语频率分类（见下文）；中文缓存解释尚未实现。
- 本地词典服务现在已有多包基础。共享 Worker 可以按词典 ID 安装、移除、打开和查询独立 SQLite 包，英语使用 ECDICT，`西` 学习语言标签激活时使用 `spanish-wiktionary`。西班牙语查词显示收藏星级和掌握卡片，背后使用西班牙语作用域的收藏、复习和手动掌握记录。
- 词典、收藏和行内查词详情会根据音标或相邻声音控件朗读当前单词，使用当前口音、声音和语速设置。
- 行内右键词典详情按内容调整大小，宽度在 471–800px 之间，高度最多 640px（行会换行；只先显示前五条英语定义，直到点击 `展开全部`，此时保持弹窗高度并在内部滚动其余内容，用 `收起` 再折叠），并根据可用视口空间定位在源文本上方或下方。
- 词典词形按名词、时态、分词、比较、原形和兜底类别紧凑分组；空类别会省略，但不会丢弃已存储形式。
- 词典详情中的屈折形式可导航：选择某个形式会在当前详情上下文中加载该形式的词典详情，或从行内查词打开完整词典详情。
- Supabase Google 身份认证和第一阶段跨设备同步已实现。Supabase SDK 固定在本地，localhost 读取项目打包的公共配置，生产公共配置由 Vercel 环境变量提供，并且已验证部署后的 Google 登录。过时的用户可编辑 Supabase 配置 UI 和浏览器存储覆盖已移除。在当前调试阶段，登录会执行一次云端读取，但所有自动写入均禁用；登录账号菜单提供显式手动同步操作。
- `npm run build` 创建一次性 `dist/`，其中只包含浏览器运行时文件，并从 Vercel 构建环境变量注入公共 Supabase 配置。
- 顶部控件包括主题、句库、设置和用户。设置是类似 词库 的三列对话框（分类、所选分类的控件、跟随指针的说明列）；快捷键配置位于其中，当设置、用户菜单或句库对话框打开时，学习快捷键暂停。
- 顶层 `收藏` 视图的 `单词` 标签使用与 `词库` 相同的可调整大小、自适应分页三列交互：左侧单词分类，中间所选收藏，右侧条目详情。单词列表显示词形，并可直接编辑收藏等级，支持紧凑英语单词搜索、分页和无滚动条的方向键导航，页大小从可用高度推导。右侧评分通常显示可编辑的黄色收藏星级，但柯林斯排序激活时切换为只读紫色 Collins 星级。悬停或选择单词会在右侧详情面板渲染完整词典信息；详情标题与词典查词共用 `自动发音` 开关，并在启用时朗读新显示的单词。键盘导航和指针接管使用与 `词库` 相同的单高亮行为，因此静止指针或旧键盘焦点不会留下第二个边框。分类过滤使用固定顺序 `Oxford 3000, 中考, 高考, CET4, CET6, 考研, IELTS, TOEFL, GRE`，没有 Collins 分类；排序仍支持 Collins 星级。收藏等级和 Collins 等级排序都按星级降序，同等级内按字母序，匹配完整词典的 Collins 排序。详情徽章在该序列中分别使用默认文字颜色，并配红色、橙色、黄色、黄绿色、绿色、蓝绿色、青色、青蓝色和蓝色描边。Collins 标签也使用默认文字颜色，带紫色描边和紫色星级。`句子` 标签移除右侧详情面板（两列而非三列）——见下方句子收藏条目。
- 顶层 `词库` 视图通过数据库分页浏览完整已安装词典。其可调整大小的对话框根据可用列表高度推导页大小，保持行固定且紧凑，因此不需要列表滚动条。每个英语和西班牙语行末尾都有可直接编辑的黄色收藏星级；更改某一行或对应详情面板会立即更新另一处。右侧详情标题也显示右键查词使用的共享 `自动发音` 开关，启用时会朗读新显示详情。Collins 星级在英语详情中保留为元数据，而不是占用列表列。英语分类默认 Oxford 3000，西班牙语使用字幕频率分类和排序。左列区分普通单词、连字符前缀后缀、含空格短语和特殊条目。进入 `后缀`、`短语` 或 `特殊` 会把仍启用的分类过滤默认设为 `全部`；学习者之后仍可为该类型选择其他分类。返回 `单词` 时，会在当前会话内分别恢复英语和西班牙语之前的单词分类。
- 词典查词和详情视图使用五星收藏等级。点击某颗星设置 1–5 级；再次点击当前等级会移除收藏。右键查词停留在所选单词附近，但在空间允许时把词典弹窗放在英语源句正下方，否则放在该行上方，因此不会遮住原句，除非被推到整个练习面板下方。旧版无等级收藏词按一星读取，并可按等级排序。收藏按云账号 ID 或本机用户名分离，并以本地形式存储词典条目及其来源句子和翻译。它们尚未包含在云同步中。
- 听力页英语源行末尾有五星句子收藏控件，交互与单词星级相同；原句会换到多行而不是截断，星级评分固定在最右侧。句子收藏按身份存储在 `langLSRWUserSentences:*` 下，包含句子、翻译、来源 ID、句库 ID 和句库标签，并按大小写和空白不敏感的文本去重。它们是复习池的句子部分，不是另一个句库，尚未包含在备份导出或云同步中。
- `收藏` 的 `单词` 标签在收藏词上方显示 `背单词：预习(n) 复习(n) 测验(n)`。三个入口使用同一组单词和同一份掌握记录，但代表三种流程：预习只练本组待学新词且不写记录，复习就是之前的自由练习，练全部已学词且不写记录，测验先练到期旧词再练本组新词并写记录。`预习(n)` 是本组待学新词数，`复习(n)` 是当前范围已学词数，`测验(n)` 是所选分类下已掌握的单词数。进入任一流程的单词都会完成识义、听写、默写，且同一分区内会把所有题目完全打乱，避免同一个词连续三项。掌握要求默认是间隔至少 21 天、至少 3 次成功重复、且一词三项全对后产生的最新结果为 `good`；间隔天数和连续答对次数可在 `设置` → `练习` 中调整。对话框按当前题型切换识义、听写、默写界面，在右侧侧面板显示答题结果，因此不会改变大小或跳动，并阻止方向键传到底层列表。所有单词练习对话框支持右键查词：优先查询鼠标点中的当前学习语言单词，点不到具体词时查询当前卡片单词。识义是自动评分的五答案练习，拼写模式自动评分并提供字母级反馈；默写显示词性、释义、首字母和字母数来区分同义词目标。任一环节答错或用提示，会使这个词本轮按答错处理，三项完成后才更新同一份本地 SM-2 风格计划，答错的词会在同一会话稍后整组三项重练。悬停启动器会在单词详情面板显示一段通俗的六部分记忆机制说明，并带当前范围统计；它会保留以便滚动，直到悬停某个单词。收藏和词库的单词行在连续分隔线前显示一个共享状态图标（🕗 到期、📕 未到期、✅ 已掌握），单词详情掌握卡片显示统一状态（包括 已到期）、间隔、下次复习、间隔系数和连续答对。点击行内状态图标会切换整词 手动掌握🟢 标记：它不改变测验记录，计为已掌握，并把该词从普通轮次中移除，直到取消。
- `收藏` 和 `词库` 的单词筛选控件拆成 `分类`、`测验`、`排序` 三个选择项。`测验`提供`全部`、`未测验`、`已测验`、`未到期`、`已到期`、`已掌握`：`未测验`显示没有测验记录且未手动掌握的词；`已测验`显示已有测验记录的词；`未到期`、`已到期`显示已测验且复习时间未到、已到的词；`已掌握`显示达到掌握标准或被手动掌握的词。以后统一说“测验”，不再说“学习”“已学习”“未学习”。收藏直接筛本地收藏数组；词库的`未测验`由词典 Worker 在完整词典分页中排除已有记录，`已测验`、`未到期`、`已到期`和`已掌握`从本地 `wordProgress` 记录表取词名后再批量查词典详情。筛选会同步影响列表、分页、背单词入口计数和悬停说明统计。
- `词库` 的 `排序` 选择项包含 `用户收藏`：当前分类和学习状态范围内，已收藏词排在前面，按收藏星级从高到低，同星级按 A-Z；未收藏词排在后面，按 A-Z。
- `词库` 的 `单词` 视图为完整所选 Oxford 3000、中考、高考、CET4、CET6、考研、IELTS、TOEFL 或 GRE 分类显示同样的 `背单词：预习(n) 复习(n) 测验(n)` 行；`全部` 禁用全部三个入口。分类中的所有词都使用同一套三项题型流程。进度是稀疏的、本地的、按身份区分的，并按规范化单词在 `wordProgress` 下只存储一次；分类和 收藏 只定义练习范围，所以同一单词在各处始终只有一个掌握状态。不保留旧版分类/收藏复习迁移路径。专用 Worker 请求用一次 SQLite 查询加载某个分类的单词名，按分类和排序缓存本浏览器会话的卡组，并一次只加载一张卡片的完整详情。
- 单词详情现在以紧凑的 `当前单词掌握程度` 区块结束，展示一份统一的背单词状态。它使用与启动器计数相同的掌握谓词区分 未测验、未到期、已到期 和 已掌握，并显示来自共享每词记录的复习间隔和下次计划复习时间。
- 背单词入口按钮（预习 / 复习 / 测验）悬停 0.2 秒会在按钮下方弹出菜单（限制在单词列内，右键不再使用）：只保留重置本组记录、切换本组新词、清除记忆；自由练习和新词预习不再作为悬停菜单项，因为它们已分别由主入口 `复习` 和 `预习` 承担。重置、切换和清除这类会删除测验记录的操作使用应用内确认框，不再弹浏览器原生确认框。每个练习和范围有一个固定的“本组新词”（随机抽出并记住，存为个人数据 `newWordBatch`）：正式测验的新词就是本组里还没测验过的词，全部测验过后才抽下一组；预习入口只练这些词，不计入记录；测验入口不再自动询问是否预习。进度栏的新词部分叫“新词初测”。机制见 `WORD_REVIEW.md`。
- 词库详情、收藏详情、查词弹窗和英语词典子框里，每个单词的星级左边有一个 `练习` 按钮：只练这一个词的听写卡片（显示释义），不计入记录，支持按住说话（按钮和快捷键）。英语词典子框可以多层叠加，学习英语时右键英文释义里的单词也能用英语词典查询。
- 英语词典子框现在和主查词弹窗一样显示完整的 `当前单词掌握程度` 卡片；该卡读取英语自己的 `wordProgress`，不会混用当前西语或其他学习语言的背词记录。
- 设置是居中的三列弹窗（分类、设置项、说明），见 `MECHANISMS.md`。
- 预习、复习、测验分小批做：每 10 个词为一批，本批每词的识义、听写、默写三道题打乱在一起，做完再做下一批；一个词只要答错一道题就立刻写入记录，退出时不提醒。预习、复习、测验的范围只由分类决定，收藏和词库里的 `测验` 筛选（级联菜单：全部、未测验、已测验里再分全部 / 未到期 / 已到期 / 已掌握）、搜索和排序只影响列表显示。机制见 `WORD_REVIEW.md` 第 3、5 节。`练习` 设置除每组单词/句子数量外，还可调整背单词排程的间隔扩大系数参数（初始值、最小值、最大值、答错减少量和答对增加量）以及掌握标准（掌握间隔天数、掌握连续答对次数），并提供单独的恢复默认值按钮；这些设置按身份保存，并影响之后产生或更新的背单词记录和掌握计数。
- `收藏` 对话框的 `句子` 标签把每个收藏显示为单个紧凑行（原文加星级）；翻译只在悬停/聚焦时显示，并换行而非截断。星级左侧的 `▶` 按钮会把该收藏的整个 `用户收藏` 集合载入练习，并直接跳到该句。列表按每页实际测量的渲染行高分页（句子行换行时高度会变化），不像等高单词列表那样用固定行高估算。
- 听力练习区上方工具栏把 `句库` 快速切换下拉框（常用句库 / 用户收藏 / 音频字幕）作为第一个控件，因此在常用句库、已有用户收藏和可用音频字幕间切换不再需要打开句库对话框；当前语言没有收藏句子时禁用 `用户收藏`，当前语言没有内置音频字幕材料且没有正在使用的导入音频字幕时禁用 `音频字幕`。可用项和不可用项在下拉框中用颜色和字重区分，存在不可用项时选择器本体也有淡色提示。它也会为当前活动的其他自定义来源显示一个临时、不可选择项。旁边的句子计数器是可编辑的跳转到句子输入，而不是纯文本。
- 学习者上次位置（活动句库加句子索引）会在页面加载时恢复，包括上次使用句库为 `用户收藏`（从当前收藏重建）时，而不只限于内置常用句库。
- 随机练习模式保留 10 条后退/前进历史，因此 `上一句`/`◀` 会回到最近显示过的随机句子，而不是重新随机；`下一句`/`▶` 会先沿该历史重做前进，再选一个新的随机句子。
- 听力工具栏在输入框中显示可编辑的当前句子编号，输入框文本区域随当前数字位数增长，后接永久可见的固定宽度自定义上下按钮；`/ total` 仍是右侧无边框纯文本，已移除已学数量。位置输入框聚焦时，所有学习快捷键暂停；Enter 只确认请求的句子跳转。
- 用户菜单按身份区分：Google 会话只显示账号状态和退出登录，本机会话只显示本机用户切换、JSON 导入/导出和删除。本地备份控件不再出现在全局设置或云账号模式中。全局重置仍位于设置中。
- 精简登录屏把 `langLSRW` 名称居中放在 `登录账号·云端同步` 和 `本机用户·离线保存` 上方，两种选择之间用显眼的 `or` 分隔。打开屏幕时焦点移到中性的登录容器，避免浏览器恢复的输入焦点预选某个选择。一旦用户悬停或聚焦某个选择，它会获得克制的上浮效果，并明显弱化未激活选择；指针悬停优先于保留的输入焦点。Google 登录、本地练习和用户导入使用同样的描边悬停、键盘焦点和按下反馈。窄屏会把选择垂直堆叠。
- 独立句库对话框，包含句库分类、搜索、分页预览和直接练习操作。预览中的每行也有自己的 `▶` 加载按钮（与 `收藏` 的 `句子` 标签中的按钮交互相同），会加载整个常用句库并直接跳到该行句子，而不是总从第一句开始。
- 本地静态服务器启动器会从 BAT 文件位置解析项目目录，并只停止占用端口 8848 的 Python `http.server`。

- 内置常用句库在启动时作为默认练习来源加载；只有该包无法读取时才会使用兜底示例。
- 该包使用小型带版本 `manifest.json` 和紧凑 TSV 内容；不会花费 AI token 给每个句子分类。
- 包加载后，英语、中文和 ID 搜索都在本地运行。
- 预览每页渲染 50 条记录，而不是创建 30,150 个 DOM 行。
- 选择该包会让全部 30,150 条记录可用于现有听力和口语流程。
- 情景、语法、等级和短语句库分类保留在 UI 中，但在内容加入之前保持禁用。

### 本地词典

- ECDICT 的基础 `ecdict.csv` 是初始词典构建的固定来源；较大的 `stardict.7z` 数据不用于运行时构建。
- 未修改的 ECDICT 上游源保存在 Web 仓库之外的 `../third-party/ECDICT-master/`；`ECDICT_SOURCE_DIR` 可以覆盖该维护时路径。
- `tools/build-ecdict.py` 生成 ECDICT 兼容的 SQLite 表和索引，验证数据库，创建确定性的 gzip 包，并写入带版本 manifest，包含条目数、大小和哈希。
- 当前基础构建包含 770,611 个条目。SQLite 数据库约 170.4 MB，gzip 下载包约 67.8 MB。
- `tools/build-spanish-dictionary.py` 通过 `npm run build:dictionary:es` 从 `../third-party/Spanish/kaikki.org-dictionary-Spanish.jsonl` 生成第一个 Spanish Wiktionary 包。当前西班牙语构建包含 770,716 个条目。SQLite 数据库约 416.2 MiB（436,391,936 字节），gzip 下载包约 66.8 MiB（70,042,471 字节）。包 SHA-256 为 `2a5f13af97f31a3b68e9c579b0ab5954446388f293e2e75d8c9e3645ee082bc6`。`tools/build-spanish-frequency.py` 另外从 `../third-party/Spanish/frequency/frequency.csv` 在旁边生成 `frequency.tsv`（17,458 个有排名词元），并记录在 manifest 的 `frequency` 条目中；包本身不变。
- `DictionaryService` 通过词典 ID 暴露稳定的 `status`、`install`、`remove`、`query`、`match` 和 `count` 操作。Worker 支持的 SQLite 适配器目前为独立 OPFS 数据库文件实现这些操作；未来服务器 API/MySQL 适配器可以实现同一契约。
- 设置面板显示安装状态和大小，把压缩包安装到浏览器 OPFS，支持移除，并提供显式测试查询。
- 听力源中的单词可以通过右键从已安装本地词典查询；可配置键盘快捷键查询当前单词。结果显示当前语言词典可用的元数据，不调用 AI。英语查词使用 ECDICT，显示发音、双语定义、Collins 评级、Oxford 3000 成员资格、学习标签、语料排名、解析后的词形、收藏星级和掌握卡片。西班牙语查词使用 `spanish-wiktionary`，显示其英语释义、解析后的 Wiktionary 词形、字幕频率排名、收藏星级和西班牙语作用域掌握卡片。当单 `l` 美式 `-ling`、`-led` 或 `-ler` 形式的 ECDICT 条目没有词形数据时，查词会检查对应双 `l` 拼写，并只复用其显式 `0:` 词元，从而覆盖 `traveling -> travelling -> travel` 这类空缺，而不猜测未验证词根。查词弹窗在收藏区左侧有 `自动发音` 复选框；开启时（默认开启；选择按浏览器保存），每个查到的词都会自动朗读。
- 基础词典以只读方式打开。用户词汇、笔记、覆盖、历史和复习状态必须保留在可替换的 ECDICT 数据库之外。
- SQLite WASM 通过 npm 固定，并由 `tools/vendor-sqlite-wasm.mjs` 复制到静态 vendor 资源；网站用户不需要安装 SQLite、Python 或 Node。

### 听力与听写

- 可导入 `.txt` 和 `.lrc`（仅文本，在 `自定义句库` 面板中）、粘贴句子列表，或使用内置常用句库。音频 + 字幕材料只能在 `音频字幕` 面板中导入，或把两个文件都拖放到听力页。
- 导入音频文件（例如 `.m4a` / `.mp3`）及其带时间 `.lrc` 字幕：带时间的英语行保留为音频边界，续接片段会合并成完整学习句子，并为听力、重放（带速度控制）、口语范读快捷键和 `原声对比` 播放对应原录音片段；单词重放仍使用 TTS。`句库` 对话框的 `音频字幕` 视图列出 `assets/audio/` 中按学习语言匹配的打包材料；当前内置 `Audio_Example.m4a` + `Audio_Example.lrc` 标记为英语材料，不会在西语中显示或加载。该面板也可导入新的音频 + `.lrc` 文件对；`assets/audio/` 会复制到部署构建中，因此打包材料一旦提交并部署后可公开下载。`自定义句库` / `音频字幕` 中没有翻译的句子可用浏览器内置端侧 Translator API（桌面 Chrome/Edge 138+）免费翻译；结果按英语文本缓存在本地，并在后续导入中复用。`音频字幕` 面板的 `翻译字幕` 可选择任意带时间 `.lrc`（无需加载），翻译后在第二次点击时把双语版本写回同一文件（`写入原文件`）、另存为新的 `<name>_双语.lrc`（`另存字幕文件`），或在保存对话框不可用时下载同名文件。只有翻译模型尚未在设备上时才显示下载进度，取消文件对话框会清除状态。打包的英语 `Audio_Example.lrc` 现在是双语（136 句，全部已翻译）。加载音频材料时，口音选择器默认 `原声`，并可切换到 英音 / 美音 TTS 后再切回。设置菜单的 `清除翻译缓存` 会清空本地翻译缓存，不触碰学习数据。用法、字幕格式和限制见 `AUDIO_LRC.md`。
- 原声音频播放对独立字幕行保留 0.3 秒结尾余量。由多个字幕片段组合出的句子改为在最终片段的真实下一行边界结束，保留紧密计时的最后单词。可听截止使用绑定渲染时钟的 Web Audio 增益计划，消除计时器轮询导致的刷新相关结尾差异。
- 已知字幕数据边界：机器生成字幕可能漏掉录音中存在的词、错误切分语音，或把下一个时间戳放在这些词之后。打包样例在 `has the water added.` 与 `It's kind of clarifying` 之间有一个这样的情况，录音包含 `you can see`，但 LRC 没有记录。这不是播放器重放问题；在修正本地 LRC 文本和时间戳前，应从音频上下文确定这些词属于哪句。未来工具可以加入基于波形的每句文本和边界编辑。
- 第二个打包样例边界情况发生在 `cheese-making process.` 之后：下一句发声早于机器生成时间戳，因此独立行的 0.3 秒余量仍会截到开头。这需要本地时间戳/端点修正；增加全局余量会使其他本来正确的句子结尾回退。
- 英语源文位于中文翻译上方，源文和翻译可分别显示/隐藏。源文收藏星级与第一行齐平，翻译（及其隐藏翻译遮罩）在星级列左边缘结束，`编辑` 按钮位于该列内。
- 听力工具栏在 `显示原文` 前包含持久化显示模式选择：`单句显示`、`长文显示` 和 `长文聚焦`。两个长文模式都会把源文区扩展为可滚动的 15 句上下文视图，使用较小字体（英语 18px，翻译 13px），每句显示为英语（带收藏星级）后接其翻译，当前句保留完整听写反馈、收藏、翻译编辑和语法视图，并让听写输入按已输入内容调整大小。点击另一句会切换到该句；每行都显示其翻译的 `编辑`（西班牙语中还有 `中译`），在另一行使用它会先切换到该句。两种模式都会让当前句居中；`长文聚焦` 还会淡化并轻微模糊其他句子，隐藏它们的星级和翻译按钮。
- 有顺序、随机、全文（`全文`）和错句练习模式，默认随机练习。在 `全文` 中，开始朗读（`朗读` 按钮、其快捷键或自动发音）会按句库顺序从当前句连续读到最后一句（原声音频作为一个不中断流播放，练习视图跟随；TTS 句子无停顿连续播放），然后停止；朗读时 `朗读` 变为 `停止 ⏹`，任何导航、停止、单词重放或句库/模式改变都会取消。`全文` 中的句子导航行为与顺序模式相同。
- 源文件导入和粘贴句子输入归在 Library > Custom Library 下；当前句翻译直接在练习翻译区编辑，AI 服务商设置归在全局设置菜单下。
- 练习工具栏始终显示活动句库类型（`常用句库`、`自定义句库`、`用户收藏` 或 `音频字幕`）。
- 上一句/下一句导航，默认英式英语口音，声音选择，正常与慢速重放，单词重放，以及句子切换时自动发音（工具栏复选框标为 `自动发音`，与查词弹窗一致）。
- 听写输入包含准确率、速度、停顿、流利度和错误统计。主页听写不再写入练习记录（将被句子复习替代），因此 `错句` 模式目前没有数据，并回退为句库顺序；已学数量已移除。
- 输入框起始为单行，只在输入文本换行到另一行时增长（在输入、句子切换和窗口调整大小时重新计算）；它不再复制源句高度。像源文行一样，它有一个右侧占位列（`#typingSide`），与源文收藏星级列匹配，并预留给未来输入控件；该列宽度会被测量，使已输入文本获得与源文本完全相同的宽度，并在同一单词处换行。
- 可配置键盘快捷键。练习顺序选择器和 ◀ / ▶ 按钮显示带当前模式和配置按键的悬停提示；悬停提示按最长行调整宽度。默认句子导航：Up / Down 在所有模式中按句库顺序移到上一句 / 下一句；Left / Right 跟随练习模式（顺序模式中上一句 / 下一句，随机模式中后退历史 / 新随机句）。
- Google 云账号和仅本机用户是分离的身份类型。云缓存按不可变 Supabase 用户 ID 键控，永远不会注册为以邮箱命名的本机用户。退出登录会清除活动身份并返回用户选择；选择本机用户始终是显式行为。云持久化携带与备份导出相同的个人数据文档（设置、收藏、单词复习进度、位置、语法结果）；内置常用句库和 AI API key 被排除。
- 调试阶段云写入为手动，以控制流量。登录只读取一次云端记录；学习操作、设置变更、首次登录、退出登录和切换到本机用户不会自动写入。`手动同步` 会用当前身份的个人数据文档替换账号的单个 Supabase 行；登录时逐条记录合并下载文档（较新者胜出）。内置常用句库、词典、录音、其他身份数据和 AI API key 被排除。保留的 1.2 秒防抖自动同步路径由 `AUTO_CLOUD_SYNC_ENABLED = false` 保护，供后续重新启用。

- 相似度、漏词、错词、多词和音量反馈。
- 录音播放和范读句对比控件。
- `原声对比` 按钮会在 TTS 范读和学习者自己的录音之间交替播放（朗读、暂停、录音、暂停、重复），直到停止，不涉及音频捕获、权限提示或分析。它与上方禁用的、权限较重的 `跟原声对比` 音高/声学分析实验分开。
- 实验性 `跟原声对比` 实现被保留，但入口按钮目前隐藏，因为该功能尚未成熟到可日常使用。开发启用时，它捕获 TTS 范读和学习者录音，然后在本地提供四个可切换视图：规范化相对音高曲线（`语调`）、相对 RMS 重音曲线（`重音`）、有声片段和停顿计数（`节奏`），以及 MFCC + 受限 DTW 声学差异条（`发音对比`）。不会上传任何内容，也不会生成音素级发音分数。

### AI 语法分析

- 手动 AI 触发；切换句子和普通练习从不触发付费请求。有已保存分析的句子会在翻译的 `编辑` 左侧显示 🌈；点击它显示或隐藏分析（在相邻长文句上会先切换到该句）。运行中的分析保持在启动时的句子上：加载占位不会跟随导航或 `全文` 朗读，结果到达时会停止 `全文` 朗读，并把视图返回该句以显示结果。
- 当前个人私用阶段，个人本地 API 设置存储在浏览器存储中。
- 传统英语教学语法是唯一启用的运行时框架。
- 分层语法 JSON 渲染，包含主要、一级和所有节点视图。
- 按角色设置颜色、可展开节点、注释、子节点指示和解释。节点的角色/类型标签与文本按基线对齐（不是盒子居中，因为标签的中文字体与文本的英文字体在相同行高下视觉中心不同），并且内部绝不换行；纯标点节点（由其文本上的 Unicode 标点正则匹配，而不是由标签措辞匹配）完全不显示标签。节点自身彩色边框永远不会被无关的固定像素宽度截断，任何从句类型节点（`type` 包含 `从句`）无论展开状态如何都始终显示角色色上边框。展开一个折叠节点总是只显示一层子节点；此前交互中保留展开的更深后代会先被折叠，因此重新展开节点不会恢复陈旧的多层状态。
- 同一句子的缓存分析会复用；重新分析是显式上下文菜单操作。
- 查看并复制精确 AI prompt 和原始/格式化 AI 响应。
- 紧凑工具栏只显示 `Ai语法分析`；其上下文菜单包含活动语法框架、prompt/响应查看和显式重新分析。
- Prompt 源维护在传统语法 Skill 中，并生成到 `src/generated/grammar-prompt.js`。
- SIEG2 保持为独立 Skill，并在 UI 中显示为禁用；它不包含在活动运行时 prompt 中。

- 计划中的云端优先账号模型尚未实现。正式发布前，它仍需要完整数据覆盖、离线队列/缓存策略、确定性冲突处理、schema 迁移、重试和恢复行为，以及明确的用户可见同步状态。当前整行手动同步实现不能被视为最终架构。
- API key 存储在浏览器 local storage 中，只适用于私人本地使用。
- 个人数据在 2026-09-28 重建（`src/user-data.js`、`USER_DATA.md`）：IndexedDB 中按身份、按语言划分记录，并带内存缓存；导出、导入（按记录合并，较新者胜出）、用户删除和云同步都遵循同一注册表。重构前浏览器键不再读取，也未迁移（调试阶段决定）。剩余边界：云上传仍会替换整行且不比较时间戳；导入没有完整替换选项；无效句子收藏（句库变更）会隐藏且不计数；自定义句库不存储；答题记录（`practiceEvent`、`reviewEvent`）在有功能使用前禁用。
- 公开 AI 访问前，请求必须迁移到带配额和成本控制的后端代理之后。
- 语音识别和录音依赖浏览器支持和麦克风权限。
- 已禁用的 `跟原声对比` 实验依赖浏览器标签页/系统音频捕获。其当前共享请求有意保持为 Edge 兼容的最小 `getDisplayMedia({ video: true, audio: true })`；恢复开发测试时，学习者必须在浏览器系统对话框中选择当前标签页并启用音频。其他浏览器和操作系统仍是兼容性测试目标。
- 本地 `发音对比` 视图只可视化宽泛的 MFCC/DTW 声学差异。它不会定位错误音素或单词，不判断口音正确性，也不生成发音分数。
- 网页无法自定义原生系统取色器对话框；设置面板提供 HEX 编辑。
- 生成的未压缩 SQLite 文件在打包后会有意丢弃。带版本 gzip 包是运行时资源；原始 CSV 源和开发工具不得进入网站部署。
- 浏览器词典安装需要 OPFS、Web Workers、WebAssembly、流式 fetch 和 gzip `DecompressionStream`。当前 Chromium 验证通过；Firefox 和 Safari 仍是明确的兼容性测试目标。
- Supabase 预配、Google OAuth 提供方配置、`supabase/schema.sql`、生产重定向 URL 和 Vercel 公共环境变量均已配置。任何额外部署域名也必须加入 Supabase Auth 重定向 URL，Google 登录才能返回。
- `dist/` 是生成输出，并被 Git 忽略。Vercel 在生产构建期间同时提供 `SUPABASE_URL` 和 `SUPABASE_PUBLISHABLE_KEY`；Google OAuth client secret 或任何 Supabase secret/service-role key 都不应出现在前端或 Vercel 公共构建配置中。
- 清除浏览器站点数据会移除已安装本地词典。它可以重新安装，不影响源包。
- 音频 + LRC 材料导入的音频只保存在内存中；页面重载后必须重新导入两个文件。句子边界只来自字幕时间：行会被限制为 2.5 秒 + 每词 0.6 秒，分裂句会按标点和大小写启发合并，因此不规则字幕仍可能合并不完美。
