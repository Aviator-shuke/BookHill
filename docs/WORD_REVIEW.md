# 单词记忆机制（收藏背词与词表学习）

最后更新：2026-09-28

本文档说明 `收藏`和`词库`中单词识义、听写、默写的完整机制，描述的是当前代码的实际行为。机制调整时同步更新本文档，并保持 [`MECHANISMS.md`](MECHANISMS.md) 中「Word Review (背词)」一节的英文摘要一致。

## 1. 设计原则

- **真正掌握的标志：隔了很久没复习，仍然能答对。** 刚复习完答对只是短期记忆，从没出过错也不等于记得牢。
- **每种练习只测一种能力。** 给出的线索不能泄露答案，例如默写时不播放发音，否则测到的其实是听写。
- **不熟的词多考，熟的词少考。** 复习间隔随答对次数变长，答错或靠提示才答对时变慢。
- **纯本地运行。** 不调用 AI，不联网，不产生费用。

## 2. 入口与范围

- 收藏入口显示为`背单词：识义(n) 听写(n) 默写(n)`，只练当前分类、搜索和排序筛选出的收藏词。
- 词表入口使用同一行布局。选择 Oxford 3000、中考、高考、CET4、CET6、考研、IELTS、TOEFL 或 GRE 后，从`识义(n)`、`听写(n)`、`默写(n)`中直接进入一种练习。学习完整分类，不受搜索框内容影响；当前排序决定新词顺序。
- `n`是当前分类下、该维度已经掌握的单词数，不是分类总词数，也不是本轮题数。收藏侧同时遵守各模式的星级门槛，但计数不受搜索框影响。分类只决定统计和练习范围；同一个单词无论出现在哪个词表或收藏中，读取的都是同一份掌握记录。
- `全部`不是一个学习词表，三个入口都会禁用，避免把完整 ECDICT 普通单词分类当成课程。
- 词表通过专用 Worker 请求一次读取当前分类的全部词名，并按“分类 + 排序”缓存到当前浏览器会话；音标、释义和词性仍在显示当前卡片时才读取。
- 三种练习各有独立对话框，不显示模式标签，也不能在练习过程中切换模式。
- 鼠标悬停在`识义`、`听写`、`默写`入口按钮上时，右侧单词详情区改为该练习的记忆机制说明（按钮本身不再显示黑色悬停提示）。说明分六部分：
  1. **练习范围**：收藏为几星及以上、当前分类的单词；词库为“词表【某某】中的全部单词”。下面四个统计框显示范围内`未学习 / 学习中📕 / 已掌握✅ / 已到期🕗`的词数；词库选择`全部`时不显示统计。
  2. **练习方式**：一句话说明怎么答题，不写按键和判分规则。
  3. **练习组题**：到期复习、新词学习（每轮最多 20 个，每 20 个为一组）、忘了再练。
  4. **复习时间怎么定**：答对时“下次间隔天数 = 上次间隔天数 × 间隔扩大系数”；前两次例外（1 天、3 天）；答错时间隔天数清零、10 分钟后再考；间隔扩大系数的起始值、加减、1.3–2.5 范围及 1.3 下限的作用；连续答对次数不影响间隔天数，只是掌握标准的条件之一。
  5. **掌握**：间隔天数 ≥ 21 且连续答对 ≥ 3 次；答错一次立即取消；按钮上的数字就是已掌握词数。
  6. **其他**：三种练习记录互不影响；同一单词在收藏和各词表共用一份记录；右键可自由练习或清除记忆。
- 说明面向用户：只用“答对 / 答错”“间隔天数”“间隔扩大系数”等简单说法，不出现算法名或内部术语；每条内容以 ● 列出，正文 12px，标题贴近详情区顶部，尽量不用滚动。
- 收藏和词库的单词列表中，每个单词左侧有三个固定宽度的图标位，依次对应识义、听写、默写：🟢 手动掌握，🕗 已到期，📕 学习中，✅ 已掌握，未学习留空（仍占位，保证单词对齐）。优先级为 🟢 > 🕗 > 📕 / ✅。点击图标区可设置手动掌握（见第 8 节）。练习结束或清除记忆后图标即时刷新。
- 图标位与单词之间有一条贯通整列的浅色竖线，把状态和单词分开；统计框和掌握程度卡片按状态着色：未学习灰色、学习中橙色、已掌握绿色、已到期蓝色。
- 鼠标离开按钮后说明仍保留，可以在详情区滚动查看；鼠标移到列表中的单词上（或用方向键切换）时换成该词详情；按下按钮开始练习时恢复原来的单词详情。
- 每个对话框只显示自己的标题、进度、卡片和快捷键；清除记忆放在入口行（见第 10 节）。打开期间，听写页的学习快捷键暂停，方向键也不会传到下层的收藏或词库列表；Esc 关闭当前对话框。
- 答题后，对错、正确答案和释义显示在对话框右侧弹出的结果子面板中，主对话框高度和位置不变；面板里的`下一个`或 Enter 进入下一个词。窗口较窄时，子面板改为覆盖在对话框右侧。
- 右侧结果子面板是本项目认可的练习反馈方式，今后其他练习（听、说、读、写的检查）也沿用：
  - 主对话框答题前后大小、位置都不变，结果不塞进主对话框，避免窗口变高、向上跳动。
  - 子面板与主对话框等高，从主对话框右侧滑出；顶部边框绿色表示正确、红色表示错误。
  - 子面板内依次放：结论（回答正确 / 回答错误等）、正确答案和解释（释义、原句等）、底部的`下一个`按钮；内容过长时在子面板内部滚动。
  - 主对话框内只保留选项本身的对错标记（正确项绿色、所选错误项红色），方便对照。

## 3. 星级决定进入哪些练习

星级规则只适用于收藏背词。星级是用户在收藏时手动设置的 1~5 星，逐级累加：

| 星级 | 进入的练习 |
|---|---|
| ★（未设星级按 1 星） | 识义 |
| ★★ | 识义、听写 |
| ★★★ | 识义、听写、默写 |
| ★★★★ / ★★★★★ | 同 3 星。表示"很重要"，具体作用待定 |

- 修改星级会立刻改变该词进入哪些练习。
- 修改星级不会删除已有复习记录。例如从 3 星降到 1 星，该词不再出现在默写中，但默写进度保留；以后改回 3 星，接着原来的进度继续。
- 完整词表中的每个词都可进入识义、听写和默写，不读取收藏星级，也不会自动加入收藏。

## 4. 三种练习

| 练习 | 显示给你 | 你要做 | 评分方式 |
|---|---|---|---|
| 识义 | 英文、音标、发音和 5 个答案 | 从三个候选释义、`以上都不是`、`不认识`中选择；收藏词答完后同时显示保存的原句 | 自动 |
| 听写 | 整词遮罩（不显示字母数）和发音按钮，自动朗读 | 输入拼写 | 自动 |
| 默写 | 只有中文释义、词性和整词遮罩；答完之前不朗读，朗读快捷键也无效 | 输入拼写 | 自动 |

### 自动评分（识义）

前三项是从本地词典抽取的释义候选。正确释义有 75% 概率随机放在前三项之一，另有 25% 概率不出现，此时第四项`以上都不是`是正确答案。第五项固定为`不认识`。

| 选择 | 结果 |
|---|---|
| 选中正确释义 | 答对 |
| 正确释义未出现时选择`以上都不是` | 答对 |
| 选择错误释义或错误选择`以上都不是` | 答错 |
| 选择`不认识` | 答错 |

选择后立即更新该词的统一识义记录，选项标出对错，并在右侧结果子面板显示正确释义；按 Enter 或点击`下一个`继续。候选释义优先来自当前练习范围，不足时从本地 Oxford 3000 补足，不调用 AI。识义卡片把单词、较大的音标和发音按钮紧凑排列在同一行，右侧提供可即时修改的五颗收藏星，方便在完整词表练习中直接收藏。

### 自动评分（听写、默写）

比对时忽略大小写和多余空格。

| 情况 | 结果 |
|---|---|
| 没用提示就拼对 | 答对 |
| 按过 Tab 露出字母后才拼对 | 答错（用了提示就算不会） |
| 点`不会`看答案（包括拼错时） | 答错 |

- 卡片只有两个按钮：`提示`和第二个按钮。第二个按钮在输入为空或拼错时是`不会`（点了看答案，算答错）；一旦用过提示就变成红色的`不会`；没用提示并且拼对时变成`下一个`（记为答对并直接进入下一个）；答完后是`下一个`。Enter 永远执行第二个按钮当前显示的操作。左下角一行写着 `Esc=退出；Tab=补一个字母；Enter=不会/下一个。`
- 严格判分：只要用过提示，即使最后拼对也算答错，结果面板显示“拼对了，但用了提示，算答错”。提示字母仍可用来边看边学。
- 遮罩随输入实时露出：从开头起连续打对的字母立即显示出来，提示补出的字母也显示在遮罩里。
- 答完后，遮罩中与你输入不同的字母标成红色；结果面板显示正确拼写和音标（音标可点击发音），收藏词还会显示保存的原句；听写在答完后才显示中文释义。
- 发音：答完朗读一遍。默写在拼对的一瞬间就朗读（不用等按 Enter），每个词只读一次。默写答完之前，发音图标不出现，朗读快捷键也不发音；图标出现时单词这一行高度不变。
- 听写卡片比识义、默写窄一些（520 像素，其他为 600）。
- 听写：拼对的一瞬间自动作答，右侧结果面板立即显示这个词，不用再按 Enter；用提示把字母全部补完时也自动作答并显示答案（算答错），第二个按钮变成红色的`下一个`。默写不自动作答，拼对时只是立即发音。
- 遮罩里已经露出的字母可以选中并复制（复制出来是连在一起的一个词），还盖着的字母不能选，避免作答前把答案复制走。

### 单词练习（查词页的`练习`按钮）

在词库详情、收藏详情、查词弹窗和英语词典子框里，每个单词的星级左边有一个`练习`按钮（英语词典子框里只在学习英语时显示）。点击后进入只练这一个词的听写卡片，用来在查词时立刻练一下拼写和发音。

- **不计入练习**：不改变这个词的复习间隔和掌握状态，也不会加入收藏。
- **循环练习**：`下一个`（或 Enter）重新练同一个词，直到关闭窗口或按 Esc。答错不会追加到队尾。
- **界面**：标题是`单词 · 练习`（不显示单词本身）；单词遮罩下面显示词性和最多三条中文释义，字号较小；对话框宽度随最长的一行释义自动撑宽（最窄 520 像素，最宽 760 像素）。没有右侧结果面板：答完后遮罩显示完整单词，写错的字母标红，并显示音标（点击可发音），同时朗读一遍。
- **按住说话**：释义下面有`按住说话`按钮和`识别结果`，也可以按住设置里的`按住说话`快捷键（默认空格）。每次按下都是一次全新的尝试：先清空输入框、已用的提示和上一次的答题状态（答完锁定的输入框也会解锁），松开约 0.3 秒后识别；识别到的词（不论对错）去掉标点、统一成小写后写入输入框，说对的词像拼对一样立即作答。识别时一次取最多 5 个候选，只要有一个和目标词一致就算说对，口音按设置里的口音识别。浏览器不支持语音识别时按钮变灰。

### 键盘操作

| 练习 | 按键 |
|---|---|
| 识义 | 1 / 2 / 3 / 4 / 5：直接选择并确认；↑ / ↓：移动当前选项（初始不选中任何项，第一下 ↓ 选中 1，↑ 选中 5）；Enter：确认当前选项（未选中时无效），答完后进入下一个 |
| 听写、默写 | Enter：执行第二个按钮（不会 / 下一个）；Tab：按顺序多露出一个字母（同`提示`） |
| 全部 | Esc：关闭弹窗 |

## 5. 每轮出哪些题

每种练习单独出题，顺序如下：

1. 当前来源和练习中**已到期**的词，最早到期的排最前；到期词没有数量上限（积压时的处理方案见第 12 节）。
2. 该练习中**从没练过**的新词，每轮最多 n 个（`设置`→`练习`→`单词练习每组 n 个`，默认 20，按用户保存），从范围内所有新词中**随机**抽取。
3. 本轮答错的词会追加到队尾，本轮稍后再考一次；如果再次答错，会再追加一次。

练习时进度栏按题目来源显示：

| 来源 | 进度栏 |
|---|---|
| 到期复习词 | `到期复习 · 第 n / 到期数 个` |
| 新词 | `新词学习 · 第 g 组 · 第 n / 本轮新词数 个`（本轮新词数通常为 20） |
| 本轮答错后追加的词 | `忘了再练 · 第 n / 追加数 个` |
| 自由练习 | `自由练习 · 第 n / 本轮题数 个 · 不计入记忆` |

新词每 20 个为一组。组号 g = 开始本轮时当前范围内该练习已学过的词数 ÷ 20 向下取整 + 1，例如已学 40 个词时本轮新词是第 3 组。收藏背词和各个词表分别计算组号。

一轮结束后显示答对、答错各几个，以及该练习下一个词的到期时间。

### 自由练习（不计入记忆）

正常一轮只出到期词和新词，所以已学过但未到期的词会暂时练不到。需要额外练习时可用自由练习：

- 入口：一轮结束（或没有待复习的词）时的`自由练习`按钮；或右键点击`识义`、`听写`、`默写`入口按钮，选择`自由练习…（不计入记忆）`。
- 出题范围：当前范围内该练习**已学过**的词，不管是否到期，随机打乱，每轮最多 20 个。收藏背词同样遵守当前分类、搜索和星级门槛；词表学习使用当前分类。
- 答题、判分和结果面板与正常练习相同，答错的词同样回到本轮队尾。
- **结果不写入复习记录**：不改变间隔、间隔扩大系数、到期时间和掌握状态。进度栏显示`自由练习 · 第 n / 本轮题数 个 · 不计入记忆`。
- 结束后可`再来一轮`（重新随机抽取）。

## 6. 复习记录

每个单词在每种练习里各有一条独立记录。记录按标准化后的单词拼写保存，不属于任何词表分类，也不属于收藏。每个词的三种练习记录和手动掌握合在一条个人数据记录 `wordProgress` 里（按身份、按学习语言，见 [`USER_DATA.md`](USER_DATA.md)）：

```json
"example": {
  "r": {
    "recognize": { "interval": 3, "e": 250, "reps": 2, "lapses": 0, "due": 1790000000000, "lastReviewedAt": "2026-09-26T08:00:00.000Z", "lastGrade": "good" },
    "listen": { ... },
    "spell": { ... }
  },
  "m": { "spell": "2026-09-26T08:00:00.000Z" }
}
```

| 字段 | 中文名 | 含义 |
|---|---|---|
| `interval` | 当前间隔（天） | 这次答对后隔多少天再考 |
| `e` | 间隔扩大系数 | 答对后下一次间隔放大的倍数，初始 2.5，最低 1.3（早期文档称“复习间隔增长系数”）。**按百分之几存成整数**：250 表示 2.5，答错减 20、答对加 5、范围 130～250；只在计算间隔（`间隔 × e ÷ 100` 后取整）和显示时除以 100。这样每一步都是精确的整数运算，不会出现 `2.3 − 0.2 = 2.0999999999999996` 这样的浮点误差（2026-09-28 改；此前的 `ease` 小数字段不再读取） |
| `reps` | 连续答对次数 | 从上次答错之后连续答对几次 |
| `lapses` | 答错次数 | 累计答错几次，只增不减 |
| `due` | 下次到期时间 | 到这个时间才会再出现 |
| `lastReviewedAt` | 上次复习时间 | 最近一次评分的时间 |
| `lastGrade` | 最近一次评分 | `good` 为答对；`again` 为答错（含用了提示）。早期版本可能留下 `hard`，现已不再产生 |

- `recognize` = 识义，`listen` = 听写，`spell` = 默写。
- 复习记录与收藏星级 `rating` 分开存放，互不影响；收藏只决定该词是否进入收藏练习范围。
- Oxford 3000、中考、高考、CET4、CET6、考研、IELTS、TOEFL、GRE 和收藏只是入口。同一拼写只对应一份三维记录，在任一入口完成练习都会更新这份记录。
- 开发阶段直接采用新结构，不读取、不合并旧的分类记录或收藏内 `review/reviews` 字段，也不保留迁移代码。
- 每次作答还可以记一条作答记录（`reviewEvent`：单词、练习方式、答对 / 答错、是否用了提示、是否自由练习、时间），用于以后的学习统计和复习池；目前没有功能读取，暂时隐藏，不写入（`USER_DATA.md` 第 4 节）。

## 7. 间隔怎么计算（简化版 SM-2）

| 结果 | 间隔 | 间隔扩大系数 | 连续答对 | 答错次数 |
|---|---|---|---|---|
| 答对（不用提示） | 第 1 次 1 天，第 2 次 3 天，之后为"上次间隔 × 系数" | +0.05（最高 2.5） | +1 | 不变 |
| 答错（含选`不认识`、用了提示、看答案） | 10 分钟后到期 | −0.2 | 清零 | +1 |

- 间隔结果四舍五入到整天。
- 连续答对次数不参与间隔的倍数计算。它只用于两件事：判断是否处在前两次（新词或答错之后，还没有可用的上次间隔，所以固定为 1 天、3 天）；以及掌握标准中的“连续答对 ≥ 3 次”。从第 3 次起，间隔只取决于上次间隔和间隔扩大系数。
- 系数范围 1.3–2.5：起始 2.5，最低 1.3，最高 2.5。
- 答对时先用当前系数计算间隔，再把系数加 0.05。早期答错过的词只要之后一直答对，系数会慢慢恢复（从 1.3 回到 2.5 需要连续答对 24 次），不会永远涨得慢。
- 间隔从**实际复习的那一刻**开始计算。到期后隔几天才复习，下次到期时间从真正答题的时刻往后推。

### 示例：一直答对的词

| 哪天复习 | 结果 | 下次复习 | 间隔 |
|---|---|---|---|
| 9/26 | 答对 | 9/27 | 1 天 |
| 9/27 | 答对 | 9/30 | 3 天 |
| 9/30 | 答对 | 10/8 | 8 天（上次间隔 3 天 × 2.5 = 7.5，四舍五入） |
| 10/8 | 答对 | 10/28 | 20 天（上次间隔 8 天 × 2.5） |

### 示例：第一次答错、之后一直答对的词

| 哪天复习 | 结果 | 下次复习 | 说明 |
|---|---|---|---|
| 9/26 | 答错 | 10 分钟后 | 从头开始，系数 2.5 → 2.3 |
| 9/26 | 答对 | 9/27 | 1 天；系数 2.3 → 2.35 |
| 9/27 | 答对 | 9/30 | 3 天；系数 2.35 → 2.4 |
| 9/30 | 答对 | 10/7 | 7 天（上次间隔 3 天 × 2.4 = 7.2）；系数 2.4 → 2.45 |
| 10/7 | 答对 | 10/24 | 17 天（上次间隔 7 天 × 2.45 = 17.15）；系数 2.45 → 2.5 |

同样连续答对 4 次后，从没答错过的词隔 20 天再考，答错过一次的词隔 17 天就考；之后系数已恢复到 2.5，两者按同样倍数增长。**越常答错或越常靠提示的词，间隔涨得越慢，考得越勤。**

### 评分两档：答对、答错

三种练习都自动判分，不需要自己评。每题结果只有两档，一轮结束时显示"答对 X · 答错 X"。代码内部分别记为 `good`、`again`：

| 练习 | 情况 | 归为 | 内部值 | 系数变化 |
|---|---|---|---|---|
| 识义 | 选对（含正确选择`以上都不是`） | 答对 | `good` | +0.05 |
| 识义 | 选错，或选`不认识` | 答错 | `again` | −0.2 |
| 听写、默写 | 没用提示拼对 | 答对 | `good` | +0.05 |
| 听写、默写 | 按过 Tab 看提示字母后才拼对 | 答错 | `again` | −0.2 |
| 听写、默写 | 拼错，或点`不会，看答案` | 答错 | `again` | −0.2 |

所以系数只在**答对**（识义选对；听写、默写不用提示拼对）时才上升。

**为什么用了提示就算答错**：最初沿用 Anki 的 Hard，把“看提示后拼对”算作中间档（间隔 × 1.2、系数 −0.15）。但 Anki 的 Hard 是“费劲但自己想起来了”，而看提示是“没想起来，靠提示补全”，更弱；而且看 1 个字母和看 7 个字母都算同一档，间隔长的词靠提示拼对后间隔还会继续拉长（例如 50 天变 60 天）。因此改为严格判分：用了提示就是不会，按答错处理，间隔清零、10 分钟后本轮再考。

### 算法来源：SM-2

本机制是 **SM-2** 算法的简化改编。SM-2 由 Piotr Woźniak 于 1987 年为 SuperMemo 设计，是最广为人知的间隔重复算法；Anki 的传统调度和 Mnemosyne 都使用 SM-2 的改进版本 [1][4][9]。

SM-2 原版要点：

- 每个条目有一个"难度系数"（E-Factor，本项目称**间隔扩大系数**），初始 2.5。
- 间隔：第 1 次 1 天，第 2 次 6 天，之后为"上次间隔 × 系数"。
- 每次复习后由学习者自评 0–5 分（q），系数按公式调整：`新系数 = 系数 + (0.1 − (5 − q) × (0.08 + (5 − q) × 0.02))`。
  - q = 5（完美）：+0.10
  - q = 4（稍有犹豫但正确）：不变
  - q = 3（很费劲才想起）：−0.14
  - q < 3（没想起来）：连续次数清零，从第 1 次间隔重新开始，**系数不变**（原文："without changing the E-Factor"）
- 系数最低 1.3。
- 每天学习结束后，把当天得分低于 4 的条目再全部复习一遍，反复直到都达到 4 分。

以上均出自 Woźniak 发布的 SM-2 原文 [1]。

核心思想：**每次在快要忘记时复习，记忆就会更牢，下一次可以隔得更久**。所以间隔按倍数增长，而倍数本身由这个词好不好记决定。

### 本项目的改编与理由

| 项目 | SM-2 原版 | 本项目 | 理由 |
|---|---|---|---|
| 评分方式 | 自评 0–5 分 | 自动判为答对 / 答错 | 自评慢且主观；识义、拼写本身就能客观判断对错 |
| 起始系数 | 2.5 | 2.5 | 沿用，经过长期验证的默认值 |
| 前两次间隔 | 1 天、6 天 | 1 天、3 天 | 单词量大、容易混淆，6 天对刚学的词偏长；Anki 默认毕业间隔为 1 天，之后按 × 2.5 增长，第二次复习大约在 2–3 天后，与 3 天接近 |
| 答错 | 从头开始，系数不变 | 从头开始，系数 −0.2，10 分钟后本轮再考 | 答错本身说明这个词难记，因此像 Anki 一样降低系数（Anki 的 Again 为 −20 个百分点）；10 分钟与 Anki 默认的重学步长一致，相当于原版"当天练到会为止" |
| 中间档 | q = 3 时 −0.14 | 不设中间档；用了提示即答错 | Anki 有 Hard（−15 个百分点，间隔 × 1.2）。本项目曾把“提示后答对”对应为 Hard，后改为严格判分，理由见“评分两档” |
| 答对 | q = 4 不变，q = 5 +0.10 | +0.05，最高 2.5 | 见下文"为什么答对要回升" |
| 系数下限 | 1.3 | 1.3 | 见下文"为什么是 1.3" |
| 系数上限 | 无 | 2.5 | 自动判分分不出"很轻松"和"刚好答对"，答对只恢复到默认水平，不超过默认值 |

### 为什么是 1.3

1.3 是 SM-2 原版就设定的下限 [1]，Anki 的 ease 同样"永远不会降到 130% 以下" [3]。

- **不设下限会怎样**：一个总忘的词系数会一路降下去。降到 1，间隔 × 1 永远不变长，这个词每隔几天就考一次，永远出不去；低于 1，间隔反而越来越短。
- **1.3 的效果**：最难的词每次答对，间隔仍至少变长 30%，只是涨得慢，会被频繁复习，但最终能拉开。
- **原作者的解释**：Woźniak 在 SM-2 原文中说明，系数低于 1.3 的条目会被过于频繁地重复，而且这类条目往往本身的表述有问题（通常是一次要记的信息太多，不符合"最小信息原则"），更好的做法是改写条目，而不是继续压低系数 [1]。对单词来说，长期卡在 1.3 的词可能需要换一种记法，例如结合例句、词根或近义词辨析。

系数不同时，同样连续答对的间隔增长（单位：天）：

| 第几次答对 | 系数 2.5（一直答对） | 系数 1.3（常答错的词） |
|---|---|---|
| 1 | 1 | 1 |
| 2 | 3 | 3 |
| 3 | 8（3 × 2.5） | 4（3 × 1.3 = 3.9） |
| 4 | 20 | 5（4 × 1.3 = 5.2） |
| 5 | 50 | 7（5 × 1.3 = 6.5） |
| 6 | 125 | 9（7 × 1.3 = 9.1） |

上表假设系数固定，用来说明倍数的影响；实际上每次答对系数还会 +0.05，常答错的词会比表中涨得稍快。

### 为什么答对要回升（+0.05）

最初的实现里系数**只降不升**：只有答错（以及当时的“提示后答对”）会降，答对不变。问题是一个词早期答错过几次、系数降到 1.3 后，就算后来已经真正记住，也一直按 1.3 倍慢慢涨。以"掌握"要求的 21 天间隔计算：

| 系数 | 连续答对时的间隔（天） | 超过 21 天需要答对 |
|---|---|---|
| 2.5 | 1 → 3 → 8 → 20 → 50 | 5 次 |
| 1.3（且不回升） | 1 → 3 → 4 → 5 → 7 → 9 → 12 → 15 → 20 → 26 | 10 次 |

早期忘过的词要多复习一倍次数才算掌握，而且这个惩罚是永久的。Anki 社区把这种现象叫 **ease hell**（系数地狱）：Anki 的 Good 不改变系数，只有按 Easy 才 +15 个百分点 [3]，多数人习惯按 Good，于是系数只降不升，越积越低。Anki 官方文档也把避免 ease hell 列为 FSRS 相对 SM-2 的优点之一 [2]。

曾考虑的三种方案：

| 方案 | 做法 | 结论 |
|---|---|---|
| A. 维持只降不升 | 不改 | 简单，但系数一旦降低就永久保留 |
| B. 答对时慢慢回升 | 每次答对 +0.05，最高 2.5 | **已采用** |
| C. 增加"很简单"评级 | 只有选它才加系数（如 +0.15，Anki 的 Easy） | 三种练习都是自动判分，没有自评按钮，需要改交互 |

选 +0.05 而不是更大的值，是为了**恢复得慢**：从 1.3 回到 2.5 需要连续答对 24 次，偶尔答对一次不会把间隔拉得太长；而真正记住的词在反复答对中逐步回到正常增长速度。计算顺序是先用当前系数算间隔，再把系数加 0.05。

Anki 社区插件 **Straight Reward**（口号"Escape Ease Hell!"）采用类似思路 [5]：连续按 Good 或 Easy 达到设定次数（"连胜"）后提高 ease，奖励 = 基础奖励 15% + 每多一次连胜 5%，只在 130%–250% 区间内起作用；插件默认关闭，启用后按其说明，连续 3 次成功可抵消一次 Hard 的扣分，连续 4 次可抵消一次 Again。本项目的 +0.05 没有连胜门槛，每次独立答对都加，但单次幅度更小，总体恢复更平缓。

### 其他产品怎么做

| 产品 / 算法 | 做法概要 |
|---|---|
| SuperMemo（SM-2，1987） | 本项目的基础，见上文 [1]。后续版本不断演进，SM-17（2016）和 SM-18（2019）改用"记忆双组分模型"：用**稳定性**（不复习时记忆能保持多久）和**可提取性**（此刻想起的概率）描述记忆，并结合条目难度计算复习时间 [6] |
| Anki（传统 SM-2 调度） | 源代码中的默认值 [8]：起始 ease 2.5；学习步长 1 分钟、10 分钟；毕业间隔 1 天，Easy 毕业 4 天；遗忘后重学步长 10 分钟，间隔清零（最少 1 天）；Hard 间隔 × 1.2，Easy 额外 × 1.3。ease 调整 [3]：Again −20 个百分点，Hard −15，Good 不变，Easy +15，最低 130%。间隔 ≥ 21 天的卡片称为"成熟卡片"（mature）[7] |
| Anki（FSRS） | Anki 23.10、AnkiMobile 23.10、AnkiDroid 2.17 起可在选项中启用 [2]。FSRS（Free Spaced Repetition Scheduler）不再用单一系数，而是为每张卡估计**难度、稳定性、可提取性**，按用户设定的目标记忆保持率（默认 90%）安排复习，参数可用自己的复习记录训练 [2] |
| Duolingo | 2016 年在 ACL 发表"半衰期回归"（Half-Life Regression，HLR）：结合心理语言学理论与机器学习，从大量学习数据估计每个词在长期记忆中的"半衰期"，再决定何时复习；预测回忆率的误差比多个基线方法降低 45% 以上 [10] |
| 墨墨背单词 | 2022 年在 KDD 发表 SSP-MMC 算法：基于约 2.2 亿条学习者记忆行为日志建立记忆模型，用随机最短路径方法安排复习，目标是以最少的复习成本记住单词，已上线墨墨背单词 [11]。论文第一作者叶峻峣（Jarrett Ye）就职于墨墨，也是 FSRS 的作者 [12] |
| 百词斩、不背单词等 | 未找到公开的调度算法说明 |

本项目目前选用简化 SM-2，因为规则透明、可解释，不需要大量历史数据训练，适合个人阶段。积累足够复习记录后，可考虑 FSRS 这类基于遗忘概率的模型（见第 12 节）。

本项目"掌握"标准中的 21 天也参考了 Anki 的"成熟卡片"定义（间隔 ≥ 21 天）[7]。

## 8. 怎样才算掌握

每条复习记录里的几个数各说明一件事，单独任何一个都不等于"已掌握"：

| 看什么 | 说明什么 | 能否单独代表掌握 |
|---|---|---|
| 间隔扩大系数 | 这个词对你好不好记 | 不能：新词也是 2.5 |
| 答错次数 | 累计答错几次 | 不能：只反映过去 |
| 距离上次复习多久 | 此刻大概还记得多少 | 不能：刚复习完当然记得 |
| **当前间隔长度** | 已经能隔多久不复习仍然答对 | **最接近真正掌握** |

当前实现把某个单词的某个维度认定为“已掌握”，必须同时满足：

1. 当前复习间隔 `interval >= 21` 天；
2. 从上次遗忘后至少成功复习 `reps >= 3` 次；
3. 最近一次评分 `lastGrade === "good"`，即无提示答对。

判分只有答对、答错两档后，答错会把连续答对次数清零，所以第 2 条成立时第 3 条必然成立。代码仍保留第 3 条作为防护（例如早期记录里的 `hard`），面向用户的说明只列前两条。

用了提示按答错处理；`again`会把间隔和连续成功次数重置，因此立即取消该维度的已掌握状态。三种维度分别判断并显示在入口的`n`中。旧记录若没有`lastGrade`，不会直接算作已掌握；该维度下次无提示答对并满足另外两个条件后再计入。

单词详情末尾的“当前单词掌握程度”按识义、听写、默写分别显示：状态（未学习 / 学习中 / 已掌握 / 已到期；到了复习时间优先显示已到期，与列表图标一致）、复习间隔、下次复习、间隔系数（即间隔扩大系数，卡片中简称，保留两位小数）和连续答对次数；未练过的各项显示“—”。单词列表左侧的三个图标位显示同样的状态（见第 2 节）。

### 手动掌握🟢

像 hello 这样很熟的词，可以不经练习直接标记为“手动掌握”。它是独立于学习记录的第五种状态：

- 点击单词列表中该词的状态图标区（收藏和词库都可以），弹出菜单：识义、听写、默写各一项“标记为手动掌握🟢”，以及“三项全部标记为手动掌握🟢”。已标记的项改为“取消手动掌握”；三项都已标记时，最后一项改为“三项全部取消手动掌握”。
- **不改动学习记录**：原来的间隔、下次复习、间隔扩大系数、连续答对都原样保留在存储中；但单词详情卡片中这几项都显示“—”，状态处显示“手动掌握🟢”（绿色）。取消手动掌握后重新显示原值。
- **统计为已掌握**：入口按钮上的已掌握数、悬停说明中的“已掌握✅”统计框都把手动掌握计算在内；它不计入未学习、学习中或已到期。
- **不再出题**：手动掌握的项不进入该练习的正常一轮（到期复习和新词学习都跳过）；自由练习仍可能抽到有学习记录的词。
- **列表图标**：该项显示 🟢，优先于 🕗 / 📕 / ✅。
- **取消后**恢复显示原来的学习状态，并重新参加练习。
- **清除某练习的记忆**时，范围内该练习的手动掌握标记也一并清除。
- 存储：保存在该词 `wordProgress` 记录的 `m` 部分（`{ recognize: 标记时间, ... }`），与学习记录 `r` 分开，互不改动。

## 9. 三种练习相互独立

- 每种练习只更新自己的记录。
- 默写答对不会让识义或听写算作答对；识义答对也不影响听写和默写。
- 不做"逐级解锁"：收藏词满足星级条件后会同时进入对应练习；完整词表中的所有词从一开始就可使用三种练习。

## 10. 清除记忆

清除操作不在练习对话框里：在`收藏`或`词库`的`背单词`入口行上，右键点击`识义`、`听写`或`默写`按钮，弹出菜单中对应的`清除识义记忆`、`清除听写记忆`或`清除默写记忆`。词库选择`全部`时入口禁用，也不能清除。

- 点击后先弹出确认框。收藏背词会清空**当前用户全部收藏词**在这一种练习里的统一记录，不受当前筛选影响；词表学习会清空当前分类所含单词的统一记录。
- 被清除的词在该练习里重新作为新词出现。
- 不影响星级，也不影响另外两种练习的记录。
- 因为同一单词只有一份记录，清除后该词在其他分类和收藏中也会同步变成未学习；不属于当前清除范围的词不受影响。
- 操作不可撤销。

## 11. 数据存储与边界

- 所有单词的统一复习记录和手动掌握保存在浏览器的个人数据库中（`wordProgress`），按身份、按学习语言分开。只保存实际学习过的词，不复制整套词典内容。
- 收藏词（`favoriteWord`）只保存单词、星级、收藏时间、筛选字段和来源句，不保存释义，也不承担掌握记录存储；背词题卡的释义、音标实时查当前语言的词典。
- 复习记录和手动掌握**包含在备份导出和云同步中**；清除浏览器网站数据会同时清除它们。详见 [`USER_DATA.md`](USER_DATA.md)。

### 参考：到期词超过一轮题量时怎么办（未决定）

现状：到期词**没有上限**，全部进入本轮并排在最前（最早到期的优先），之后再加最多 20 个新词。每答一题立即保存，中途关闭不丢进度；没练到的到期词下次仍排在最前。新词排在最后，所以到期词没做完就关闭时，本轮等于没有加入新词。

问题：长时间没练后积压很多（例如 80 个到期词），一轮会变成 80 + 20 = 100 题，看上去太长；如果真的做完，又多学了 20 个新词，几天后它们一起到期，积压反而更大。

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| A. 维持现状 | 到期词全部进入，新词固定最多 20 个 | 不用改；不会漏掉任何到期词 | 积压时一轮很长；做完后新词继续加重下次积压 |
| B. 积压时少加新词（倾向方案） | 到期词全部进入；新词数 = max(0, 20 − 到期词数)，到期词 ≥ 20 时本轮不加新词；进度栏显示"到期 N 个" | 先还旧账，积压自然消化；不漏到期词；改动小 | 积压期间学不到新词 |
| C. 每轮设总上限（如 30 个） | 超出的到期词留到下一轮；结束卡片显示"还有 X 个到期，再来一轮" | 每轮都短，心理负担小 | 需要多开几轮；上限值需要调 |

B 和 C 可以组合使用：积压时不加新词，同时每轮最多 30 题。

### 参考：新词每天最多学多少（未决定）

现状：**没有每日新词上限**。每轮最多加入 20 个新词，但一轮做完立即再开一轮，上一轮的新词已有记录、不再算新词，出题会取下一批 20 个，所以一天开几轮就能学几轮新词。

问题：一天多刷几轮，当天学的新词会在 1 天后、3 天后成批到期，正是到期词积压的主要来源。

可能的做法：

- 每种练习每天最多学 20 个新词（识义、听写、默写分开计），按本地日期计算。
- 当天额度用完后，再开一轮只出到期词，结束卡片提示"今天的新词额度已用完"。
- 自由练习不受影响，本来就不计入记忆。
- 需要记录新词是哪天开始学的：可在复习记录中增加"首次练习时间"字段，或按天单独保存计数（不改记录结构）。
- 上限值待定。

### 参考：听写遇到同音词怎么办（已定方向，未实现）

现状：听写只认目标词的拼写。像 right / write、their / there、peace / piece、caught / court（英音）这样读音完全相同的词，只听声音无法区分，写成另一个也判为答错，还会让这个词的间隔清零。这对学习者不公平，也会打乱排期。

区分两类情况：

- **真正的同音词**（读音完全相同）：听不出来，写成同音词不应算错。
- **发音相近但不相同的词**（accept / except、live / leave、ship / sheep、desert / dessert）：听得出来，只是难。这正是听写要练的，写错仍算答错。

已定方向（方案 A，2026-09-29 讨论）：

- 输入的是另一个真实单词，并且与目标词的英音音标完全相同时，不判答错、不改变排期；提示“这是同音词 *write*，要找的词意思是：……”，让学习者再写一次。
- **只按英音判断**：学习者通常只学一种口音（owner 学英音），当前词库的音标也主要是英音。选美音时暂不做同音判断，仍按原样判分；美音以后再考虑。
- 同音词对照在本地计算（词典加载时生成，或预置一份小表），不调用 AI。

当前词库（ECDICT）音标的情况（2026-09-29 抽查）：

- 基本是英音：car /kɑ:/、hot /hɒt/、tomato /tә'mɑ:tәu/；caught 与 court 都是 /kɒ:t/，their 与 there 都是 /ðєә/，right 与 write 都是 /rait/。
- 个别词混入美音或两种读法并列：bath /bæθ.bɑ:θ/、dance /dæns. dɑ:ns/（用点分隔），schedule 只标美式 /'skedʒuәl/。
- 符号是老式写法且不统一：ә、є 代替 ə、e，ɒ: 代替 ɔː，au 代替 əʊ，: 代替 ː。
- 部分词没有音标。

实现时需要：

1. 比较前先统一符号（ә→ə、є→e、ɒ:→ɔː、:→ː 等），去掉重音符号。
2. 两种读法并列的，只取英音那一种。
3. 没有音标的词不做同音判断。

其他备选（未采用）：出题时对有同音词的单词显示词性和简短释义（接近默写，露出信息）；所有听写都显示词性（很多同音词词性相同，解决不了）；再朗读一遍原句，靠上下文区分（词表中的词大多没有原句，可作为 A 的补充）。
